# PHASE 5 — Workflows and Notifications

**Status:** NOT_STARTED

## Objective
Implement team-aware workflows and reliable notifications.

## Tasks
- [ ] Default task statuses: Backlog, To Do, In Progress, In Review, Done, Blocked, Problem/Error, and Cancelled.
- [ ] Workspace-level workflow configuration for authorized roles.
- [ ] Notifications for assignment, status changes, comments, invitations.
- [ ] Keep device push registrations user-scoped.
- [ ] Prevent duplicate notifications and cross-workspace disclosure.
- [ ] Handle invalid tokens, failures, retries.

## Acceptance Criteria
- [ ] Correct recipients receive each event.
- [ ] Unauthorized members cannot retrieve event details.
- [ ] Existing reminders and notifications continue to work.
